# 4WD RC카 라인트레이서 + 초음파 장애물 회피

에듀이노(Eduino) 4휠 스마트 RC카 키트(Arduino UNO)로 만든 라인트레이서.
선을 따라 달리다가 장애물을 만나면 초음파 센서 하나와 서보로 장애물 폭을 재고, 옆으로 돌아서 다시 선으로 돌아온다.
차체·모터·센서·배선은 키트 그대로 쓰고 코드는 새로 짰다.

엔코더나 IMU가 없어서 이동 거리와 회전 각도는 전부 시간으로 정한다. 그래서 차마다, 건전지 상태마다 값을 다시 맞춰야 한다.

## 파일

```
RC_CAR_WHITE_LINE/          어두운 바탕 + 흰 선, 주행용
RC_CAR_WHITE_LINE_DEBUG/    어두운 바탕 + 흰 선, 디버그용 (시리얼 출력)
RC_CAR_BLACK_LINE/          밝은 바탕 + 검은 선, 주행용
RC_CAR_BLACK_LINE_DEBUG/    밝은 바탕 + 검은 선, 디버그용 (시리얼 출력)
TURN_TEST/                  회전 시간 맞추는 테스트 코드
docs/                       README 그림
```

| 트랙 | 상태 |
|---|---|
| 어두운 바탕 + 흰 선 | 실차 테스트 완료 (v1.0) |
| 밝은 바탕 + 검은 선 | 테스트 중 |

- 주행용은 시리얼 출력이 없어서 제일 빠르다. 실제로 달릴 때는 이걸 쓴다.
- 디버그용은 시리얼 모니터(9600 baud)에 단계별 로그를 찍는다. 출력 때문에 조금 느리다.
- 설정값을 바꾸면 같은 트랙의 주행용과 디버그용에 똑같이 적어야 같은 동작을 한다.
- 트랙을 바꾸면 라인센서 감도(가변저항)를 그 트랙에서 다시 맞춰야 한다.

## 하드웨어

| 부품 | 핀 | 비고 |
|---|---|---|
| 라인센서 3개 (TCRT5000) | A5 왼쪽, A4 가운데, A3 오른쪽 | 흰색 = 0, 검은색 = 1 |
| 초음파 센서 | Trig 13, Echo 12 | 거리(mm) |
| 서보 | 2 | 초음파 센서를 좌우로 돌림 |
| 모터 드라이버 | PWM 5, 6 / 방향 8, 9, 10, 11 | 좌우 바퀴 |

## 동작 흐름

```mermaid
flowchart TD
    A[전원 켜짐] --> B{60ms마다 정면 거리 측정}
    B -- 장애물 없음 --> C[라인 따라가기]
    C --> B
    B -- AVOID_MM 안쪽 --> D[멈추고 한 번 더 측정]
    D -- 잡음 --> C
    D -- 진짜 장애물 --> E[회피]
    E --> C
```

라인센서는 계속 읽고, 초음파는 60ms 간격으로만 쏜다. 너무 자주 쏘면 앞에서 쏜 소리의 메아리가 섞여서 가짜 값이 나온다.

달리는 중에는 정면에 뭐가 있는지만 확인하고 멈추지 않는다. 장애물이 보이면 멈춘 다음 한 번 더 재서 확인하고, 회피 중의 측정(폭 재기, 옆 확인)은 전부 멈춘 상태에서 한다.

## 라인 따라가기

### 흰 선 버전 (선 = 0)

| 왼쪽 | 가운데 | 오른쪽 | 동작 |
|:---:|:---:|:---:|---|
| 1 | 0 | 1 | 직진 |
| 1 | 0 | 0 | 왼쪽으로 살짝 보정 |
| 1 | 1 | 0 | 왼쪽으로 크게 보정 (제자리에서 틀기) |
| 0 | 0 | 1 | 오른쪽으로 살짝 보정 |
| 0 | 1 | 1 | 오른쪽으로 크게 보정 (제자리에서 틀기) |
| 0 | - | 0 | 정지 |
| 1 | 1 | 1 | 선 놓침. 하던 동작 유지, 20초 지나면 정지 |

### 검은 선 버전 (선 = 1, 센서 값 그대로)

| 왼쪽 | 가운데 | 오른쪽 | 동작 |
|:---:|:---:|:---:|---|
| 0 | 1 | 0 | 직진 |
| 0 | 1 | 1 | 오른쪽으로 살짝 보정 |
| 0 | 0 | 1 | 오른쪽으로 크게 보정 (코너) |
| 1 | 1 | 0 | 왼쪽으로 살짝 보정 |
| 1 | 0 | 0 | 왼쪽으로 크게 보정 (코너) |
| 1 | - | 1 | 0.5초(`LINE_GRACE_MS`) 동안 하던 동작 유지, 그 뒤 정지 |
| 0 | 0 | 0 | 선 놓침. 2초(`LOST_STOP_MS`) 동안 마지막으로 선을 본 쪽으로 돌면서 찾고, 못 찾으면 정지 |

검은 선 버전은 속도 설정도 다르다(직진 `SPEED` 100, 크게 보정 `TURN_SPEED` 170).

## 장애물 회피

움직이면서 그때그때 판단하면 센서 값 하나만 튀어도 엉뚱하게 꺾여서, 멈춰서 먼저 재고 그 값대로 움직이게 했다.

```mermaid
flowchart TD
    S[장애물 앞에서 정지] --> M["1. 폭 재기"]
    M -- 아무것도 없음 --> X[가짜 감지, 회피 취소]
    M --> T["2. 짧은 쪽으로 약 90도 돌기"]
    T --> P1["3. 잰 폭 + 여유만큼 옆으로 직진"]
    P1 --> T2["4. 장애물 쪽으로 약 90도 돌기"]
    T2 --> P2["5. 옆을 보면서 지나가기"]
    P2 --> R["6. 선 쪽으로 45도 꺾기"]
    R --> F["7. 비스듬히 직진하며 선 찾기"]
    F --> L["8. 선 위에 정렬, 라인 주행으로 복귀"]
```

오른쪽으로 피하는 경우를 위에서 본 그림. 차는 아래에서 위로 달린다. 왼쪽으로 피할 때는 좌우만 반대다.

<p align="center">
  <img src="docs/avoid-path-v3.svg" alt="장애물 회피 경로" width="520">
</p>

1. 폭 재기: 서보를 정면 기준 ±70도까지 10도씩 돌리며 거리를 잰다. 장애물로 보이는 각도에서 `거리 × sin(각도)`로 좌우로 뻗은 길이를 구해 저장한다.
2. 돌기: 짧게 뻗은 쪽으로 약 90도 돈다. 시간으로 도는 거라 딱 90도는 아니고 조금 비스듬하다.
3. 옆으로 나가기: 저장한 폭 + 여유만큼은 무조건 직진하고, 그 뒤에도 옆에 장애물이 보이면 조금씩 더 간다.
4. 다시 돌기: 장애물 쪽으로 약 90도 돌아서 원래 진행 방향으로 선다.
5. 지나가기: 서보로 옆을 보면서 조금 전진, 정지, 측정을 반복한다. 옆에 안 보이면 다 지나간 것.
6. 45도 꺾기: 선 쪽으로 45도 튼다.
7. 직진: 비스듬히 가면서 라인센서로 선을 찾는다.
8. 라인 복귀: 선을 찾으면 가운데 센서가 선을 볼 때까지 원래 방향으로 돌고 라인 주행으로 돌아간다.

## 튜닝

조절하는 값은 각 `.ino` 파일 맨 위 `[설정]`에 모여 있다. 시간 단위는 전부 ms.

| 값 | 설명 |
|---|---|
| `TURN_RIGHT_90_MS`, `TURN_LEFT_90_MS` | 2, 4번 90도 회전 시간. 좌우 모터 힘이 달라서 방향별로 따로 둠 |
| `TURN_RIGHT_45_MS`, `TURN_LEFT_45_MS` | 6번 45도 회전 시간 |
| `AVOID_TURN_SPEED` | 회피 회전 속도. 멈춘 상태에서 돌기 시작해서 라인 보정보다 세게 둠 |
| `MM_PER_SEC` | 1초에 가는 거리. 잰 장애물 폭을 시간으로 바꿀 때만 씀 |
| `AVOID_MM` | 이 거리 안에 장애물이 보이면 회피 시작 |
| `AVOID_SIDE` | 0 자동, 1 무조건 오른쪽, 2 무조건 왼쪽 (한쪽씩 테스트할 때) |
| `SERVO_FLIP` | 서보 좌우가 반대로 달렸으면 1 |
| `SIDE_MARGIN_MM` | 옆으로 나갈 때 장애물 폭에 더하는 여유. 긁히면 늘림 |
| `PASS_STEP_MS` | 지나갈 때 한 번에 전진하는 시간 |
| `PASS_EXTRA_MS` | 장애물이 안 보이게 된 뒤 더 가는 시간 |
| `RETURN_MAX_MS` | 45도 꺾고 선을 찾으며 직진하는 최대 시간 |

지금 들어 있는 회전 값(오른쪽 90도 550ms, 왼쪽 90도 900ms, 45도 500ms, 회전 속도 170)은 이 차에서 잰 값이다. 다른 차나 다른 바닥에서는 다시 재야 한다.

### 회전 시간 맞추기

`TURN_TEST/TURN_TEST.ino`를 올리고 시리얼 모니터(9600 baud)를 연다. 바닥에 테이프로 차 방향을 표시해 두고 한 글자씩 보내면서 맞춘다. 실제로 달릴 바닥에서 해야 마찰이 같다.

| 입력 | 동작 |
|:---:|---|
| `r` / `l` | 오른쪽 / 왼쪽 90도 |
| `e` / `q` | 오른쪽 / 왼쪽 45도 |
| `+` / `-` | 방금 돌린 값 ±20ms |
| `p` | 지금 값 출력 |

다 맞으면 `p`로 나온 값을 쓰는 `.ino` 파일에 옮겨 적는다. 전원을 끄면 처음 값으로 돌아가니까 끄기 전에 `p`로 확인해 둘 것.

### 라인센서 감도 맞추기

라인센서마다 파란 가변저항이 있다. 센서를 하나씩 선 위와 바탕 위에 번갈아 놓고, 센서 모듈의 LED가 확실히 바뀌는지 본다. 안 바뀌면 가변저항을 조금씩 돌려가며 맞춘다.

센서 높이가 바뀌거나 트랙, 조명이 바뀌면 다시 맞춰야 한다. 햇빛이 드는 곳에서는 값이 흔들리니 실제로 달릴 곳에서 맞추는 게 좋다.
